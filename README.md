# SoC

Группа **ИУ5-51Б**, вариант **1**.

| Оценка | Задание |
| --- | --- |
| «3», №23 | Пройти по массиву и заменить нулями повторяющиеся подряд элементы. Программа — в машинном коде, данные и результат — в RAM. |
| «4», №17 | Управление гаражными воротами: кнопки пульта, концевые выключатели открытого и закрытого положения, ИК-датчик препятствия. Нужны ассемблер, программа на своей ISA и MMIO. |
| «5», №28 | Измеритель реакции: случайная задержка, светодиод, измерение времени до нажатия кнопки в микросекундах, лучший результат на 7-сегментном дисплее. Кастомная инструкция `HIGH_RES_TICK` захватывает значение таймера по фронту сигнала кнопки. |

## Запуск

Сборка программы ассемблером и запуск её на SoC в симуляции Verilator:

```bash
cargo run --bin asm -- asm/duplicates_to_zero.asm -o build/dup
cargo run -- build/dup
```

Первая команда создаёт `build/dup.rom.hex` и `build/dup.ram.hex`, см. [docs/ASM.md](docs/ASM.md). Вторая выполняет программу до `HALT` и печатает число тактов, светодиоды, выходы ворот и ненулевые слова RAM. Если `HALT` не наступает, симуляция работает, пока её не прервут (Ctrl+C). Первый запуск дольше, потому что Verilator собирает модель; прерывать его до окончания сборки не стоит.
