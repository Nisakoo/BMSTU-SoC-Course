# АЛУ

Комбинационный блок: тактового сигнала нет, результат зависит только от входов в данный момент.

## Порты

| Порт | Ширина | Направление | Откуда / куда |
| --- | --- | --- | --- |
| `a` | 32 | вход | `rd1` регистрового файла |
| `b` | 32 | вход | MUX B (`rd2` или `imm`) |
| `op` | 4 | вход | `alu_op` из микрокоманды |
| `r` | 32 | выход | MUX WB и регистр адреса |
| `nzcv` | 4 | выход | регистр флагов, порядок `{N, Z, C, V}` |

## Операции

| `op` | Операция | Результат `r` | C | V |
| --- | --- | --- | --- | --- |
| `0000` | ADD | `a + b` | перенос из старшего разряда | знаковое переполнение |
| `0001` | SUB | `a − b` | заём: 1, если `a < b` как беззнаковые | знаковое переполнение |
| `0010` | AND | `a & b` | 0 | 0 |
| `0011` | OR | `a \| b` | 0 | 0 |
| `0100` | XOR | `a ^ b` | 0 | 0 |
| `0101` | NOT | `~a` (`b` не используется) | 0 | 0 |
| `0110` | SHL | `a << b[4:0]`, справа нули | 0 | 0 |
| `0111` | SHR | `a >> b[4:0]`, слева нули | 0 | 0 |
| `1000` | SAR | `a >> b[4:0]`, слева копии знакового бита `a` | 0 | 0 |

Коды `1001`–`1111` свободны. При неиспользуемом коде `r = 0`.

## Сдвиги

Величина сдвига — младшие 5 бит `b` (0–31), остальные биты `b` игнорируются. Сдвиг на 0 возвращает `a` без изменений. Выдвинутые биты теряются: C у сдвигов всегда 0. N и Z считаются по результату, как у остальных операций.

`CMP` — это SUB, результат которого не записывается в регистр: меняются только флаги.

## Флаги

| Флаг | Как считается |
| --- | --- |
| N | `r[31]` |
| Z | 1, если `r == 0` |
| C | см. таблицу операций |
| V | см. таблицу операций |

Сам регистр флагов — отдельный блок, он запоминает `nzcv` по сигналу `flags_we`.

## ADD и SUB

Вычисление ведётся на 33 битах: к каждому операнду слева дописывается нулевой бит, результат записывается в 33-битную величину `wide`. Младшие 32 бита идут в `r`, старший (`wide[32]`) — в C. При вычитании этот бит равен 1, если был заём.

Знаковое переполнение V:

| Операция | Условие |
| --- | --- |
| ADD | знаки `a` и `b` совпадают, а знак `r` другой |
| SUB | знаки `a` и `b` разные, а знак `r` отличается от знака `a` |

Числа хранятся в дополнительном коде, поэтому одно и то же сложение и вычитание подходит и для знаковых, и для беззнаковых значений. Беззнаковый результат читают по C, знаковый — по N и V.
