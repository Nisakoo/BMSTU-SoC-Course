# ROM инструкций

Память команд: 1024 слова по 32 бита, только чтение. Код: `rtl/rom.v`.

## Параметр

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `INIT_FILE` | `""` (пустая строка) | путь к hex-файлу с образом программы; если пусто, ROM остаётся заполненной нулями |

## Порты

| Порт | Ширина | Направление | Откуда / куда |
| --- | --- | --- | --- |
| `addr` | 10 | вход | `PC` |
| `data` | 32 | выход | `I`, в регистр команды IR |

Тактового сигнала у ROM нет, порта записи тоже нет.

## Работа

**Чтение.** Комбинационное: `data` показывает слово по адресу `addr` сразу, без такта, и меняется вслед за адресом.

**Начальное содержимое.** В начале симуляции все 1024 слова становятся 0. Затем, если `INIT_FILE` задан, образ загружается из файла командой `$readmemh`. Слова, которых нет в файле, остаются нулями.

**Запись.** Записать в ROM во время работы нельзя: содержимое задаётся только при старте.

## Формат hex-файла

Файл читает `$readmemh`:

| Элемент | Смысл |
| --- | --- |
| строка `DEADBEEF` | 32-битное слово в шестнадцатеричном виде; слова идут подряд, начиная с адреса 0 |
| строка `@100` | следующее слово записывается по адресу `0x100`; адрес тоже в шестнадцатеричном виде |

Пример:

```
@000
DEADBEEF
00000001
@3FF
FFFFFFFF
```

Здесь слова по адресам `0x000`, `0x001` и `0x3FF`, остальные ячейки равны 0.

## Путь к файлу

Путь в `INIT_FILE` отсчитывается от каталога, из которого запущена симуляция. При запуске `cargo test` это корень проекта, например `tests/data/rom_test.hex`.

## Проверка

Параметр `INIT_FILE` в Rust не задать, поэтому тесты подключают ROM через обёртки в `tests/rtl/`:

| Файл | Модуль | Содержимое |
| --- | --- | --- |
| `tests/rtl/rom_program.v` | `rom_program` | ROM, загруженная из `tests/data/rom_test.hex` |
| `tests/rtl/rom_empty.v` | `rom_empty` | ROM без файла |

Тесты находятся в `tests/rom_test.rs`, 8 проверок: чтение записанных слов, нули в остальных ячейках, первый и последний адрес, независимость каждого бита адреса, чередующиеся биты, комбинационное чтение, неизменность содержимого при чтении, ROM без файла.
