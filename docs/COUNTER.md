# Счётчик

Синхронный счётчик с параметризуемой шириной, сбросом и загрузкой значения. Код: `rtl/counter.v`.

## Параметр

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `WIDTH` | 8 | ширина счётчика в битах |

## Порты

| Порт | Ширина | Направление | Назначение |
| --- | --- | --- | --- |
| `clk` | 1 | вход | тактовый сигнал, всё происходит по фронту 0 → 1 |
| `reset` | 1 | вход | синхронный сброс в 0 |
| `load` | 1 | вход | загрузить `load_value` |
| `load_value` | `WIDTH` | вход | значение для загрузки |
| `count` | `WIDTH` | выход | текущее значение счётчика |

## Работа

На каждом фронте `clk` выполняется ровно одно действие, по приоритету:

| Приоритет | Условие | Новое значение `count` |
| --- | --- | --- |
| 1 | `reset = 1` | 0 |
| 2 | `load = 1` | `load_value` |
| 3 | иначе | `count + 1` |

- Сброс синхронный: пока нет фронта `clk`, изменение `reset` на `count` не влияет.
- Если `reset` и `load` равны 1 одновременно, выполняется сброс.
- После максимального значения (`2^WIDTH − 1`) счётчик переходит в 0.
- До первого сброса значение `count` не определено.

## Использование

Внутри другого модуля счётчик создаётся с нужной шириной:

```verilog
counter #(.WIDTH(4)) u_cnt (
    .clk       (clk),
    .reset     (reset),
    .load      (load),
    .load_value(load_value),
    .count     (count)
);
```

## Проверка

Макрос `#[verilog]` в Rust не принимает выражения в ширине портов (`[WIDTH-1:0]`), поэтому тесты подключают счётчик через обёртки с фиксированной шириной:

| Файл | Модуль | Ширина |
| --- | --- | --- |
| `tests/rtl/counter4.v` | `counter4` | 4 |
| `tests/rtl/counter8.v` | `counter8` | 8 |

Тесты находятся в `tests/counter_test.rs`: по 10 проверок для каждой ширины (сброс, счёт, переполнение, загрузка, приоритет сброса над загрузкой, срабатывание только по фронту, синхронность сброса).
