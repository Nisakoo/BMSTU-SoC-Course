# RAM данных

Память данных: 1024 слова по 32 бита, чтение и запись. Код: `rtl/ram.v`.

## Параметр

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `INIT_FILE` | `""` (пустая строка) | путь к hex-файлу с начальными данными; если пусто, RAM заполняется нулями |

## Порты

| Порт | Ширина | Направление | Откуда / куда |
| --- | --- | --- | --- |
| `clk` | 1 | вход | тактовый сигнал |
| `addr` | 10 | вход | адрес слова из «Декодера адреса»; один и тот же для чтения и записи |
| `we` | 1 | вход | разрешение записи из «Декодера адреса» |
| `wd` | 32 | вход | данные для записи из «Декодера адреса» |
| `data` | 32 | выход | слово по адресу `addr`, в «Декодер адреса» |

У RAM нет сигнала сброса: содержимое не стирается.

## Работа

**Чтение.** Комбинационное: `data` показывает слово по адресу `addr` сразу, без такта, и меняется вслед за адресом.

**Запись.** По фронту `clk` 0 → 1, если `we = 1`, слово `wd` записывается по адресу `addr`. Остальные слова не меняются. Если `we = 0`, ничего не записывается. Спад `clk` на содержимое не влияет.

**Чтение и запись в одном такте.** Пока фронта `clk` не было, `data` показывает старое значение слова, в которое идёт запись. После фронта показывает новое.

**Начальное содержимое.** В начале симуляции все 1024 слова становятся 0. Затем, если `INIT_FILE` задан, данные загружаются из файла командой `$readmemh`. Слова, которых нет в файле, остаются нулями. Так в RAM можно заранее положить исходные данные программы, например массив для задания «3».

## Формат hex-файла

Тот же, что у ROM инструкций, см. [ROM.md](ROM.md): 32-битные слова в шестнадцатеричном виде по одному в строке и директива `@адрес` для смены адреса.

## Путь к файлу

Путь в `INIT_FILE` отсчитывается от каталога, из которого запущена симуляция. При запуске `cargo test` это корень проекта, например `tests/data/ram_test.hex`.

## Проверка

Модуль без файла тесты подключают напрямую. Для проверки загрузки нужна обёртка, потому что параметр `INIT_FILE` из Rust не задать:

| Файл | Модуль | Содержимое |
| --- | --- | --- |
| `tests/rtl/ram_program.v` | `ram_program` | RAM, загруженная из `tests/data/ram_test.hex` |

В `ram_test.hex` записан массив `1, 1, 2, 2, 2, 3, 4, 4` по адресам `0x000`–`0x007` и слово `0xCAFEBABE` по адресу `0x3FF`.

Тесты находятся в `tests/ram_test.rs`, 14 проверок:
- **RAM без файла:** нули, запись и чтение каждого адреса, запись меняет только свою ячейку, первый и последний адрес, независимость каждого бита адреса, все 32 бита данных, перезапись, `we = 0`, комбинационное чтение, запись только по фронту `clk`.
- **RAM с файлом:** загруженные слова, нули в остальных ячейках, такты без `we` не портят данные, запись поверх загруженного слова меняет только его.
