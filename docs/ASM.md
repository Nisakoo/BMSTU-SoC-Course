# Ассемблер: шпаргалка

Кодировки, флаги и микрокоманды — в [ISA.md](ISA.md). Здесь только синтаксис.

## Строка

```
метка:  КОМАНДА  операнды   ; комментарий
```

- Комментарий начинается с `;` и идёт до конца строки.
- Метка — имя и двоеточие. Может стоять на своей строке или перед командой.
- Одна команда на строку.

## Регистры

`R0`–`R15`. `R0` всегда равен 0, запись в него игнорируется.

## Числа

| Формат | Пример |
| --- | --- |
| десятичное, возможен `-` | `10`, `-976` |
| шестнадцатеричное | `0x3F`, `0xCAFEBABE` |
| двоичное | `0b1010` |
| символ | `'a'` (код символа) |

## Команды

Операнды: `rd` — приёмник, `rs1`, `rs2` — регистры, `imm` — число, константа или имя из `.equ`. Для команд с `imm` в конце мнемоники стоит `I`.

| Команда | Операнды | Действие |
| --- | --- | --- |
| `HALT` | — | остановка |
| `ADD`, `SUB` | `rd, rs1, rs2` | сложение, вычитание |
| `AND`, `OR`, `XOR` | `rd, rs1, rs2` | побитовые операции |
| `NOT` | `rd, rs1` | побитовое НЕ |
| `SHL`, `SHR`, `SAR` | `rd, rs1, rs2` | сдвиг влево, логический вправо, арифметический вправо |
| `CMP` | `rs1, rs2` | сравнение, меняет только флаги |
| `ADDI`, `SUBI` | `rd, rs1, imm` | то же, что `ADD`, `SUB`, с константой |
| `ANDI`, `ORI`, `XORI` | `rd, rs1, imm` | то же, что `AND`, `OR`, `XOR`, с константой |
| `SHLI`, `SHRI`, `SARI` | `rd, rs1, imm` | то же, что `SHL`, `SHR`, `SAR`, с константой |
| `CMPI` | `rs1, imm` | сравнение с константой |
| `LOAD` | `rd, imm(rs1)` | `rd ← память[rs1 + imm]` |
| `STORE` | `rd, imm(rs1)` | `память[rs1 + imm] ← rd` |
| `JUMP` | `метка` | безусловный переход |
| `BEQ`, `BNE` | `метка` | переход, если равно / не равно (Z) |
| `BLTU`, `BGEU` | `метка` | переход, если меньше / не меньше (без знака, C) |
| `JAL` | `rd, метка` | вызов: адрес возврата в `rd`, переход |
| `JR` | `rs1` | переход по адресу из `rs1` |
| `HIGH_RES_TICK` | `rd` | `rd ← значение захвата`, Z = 1, если захвата не было |

В переходах вместо `imm` пишется метка. Смещение ассемблер считает сам, от следующей команды.

## Директивы

| Директива | Действие |
| --- | --- |
| `.equ имя, значение` | константа; имя подставляется вместо числа |
| `.text` | дальше идут команды, они попадают в ROM (действует с начала файла) |
| `.data` | дальше идут данные, они попадают в RAM |
| `.word v1, v2, ...` | слова данных (только в `.data`) |
| `.org адрес` | адрес следующей команды или слова в текущем образе, в словах |

- Метка в `.text` — адрес команды в ROM, в `.data` — адрес слова в RAM.
- Ассемблер выдаёт два образа: ROM команд и RAM данных.
- Для MMIO значение `.equ` равно `BASE − 1024` (адрес `0xFFFFFC00 + BASE` через `imm(R0)`), см. [DEVICES.md](DEVICES.md).

## Формат программы

- Заголовка, точки входа и обязательных секций нет. Код можно писать с первой строки: до первой `.data` действует `.text`.
- Первая команда файла лежит в ROM по адресу 0, с неё процессор начинает после сброса.
- `.data` нужна только если есть данные в RAM. Вернуться к коду можно через `.text`.
- Программа заканчивается командой `HALT`. Пустые ячейки ROM тоже читаются как `HALT`.

## Пример

```
.equ LED, -976

        .data
        .org  0
arr:    .word 1, 1, 2, 'a', 0x10

        .text
        LI    R1, 8           ; счётчик
loop:   STORE R1, LED(R0)     ; вывести на светодиоды
        SUBI  R1, R1, 1
        BNE   loop            ; пока R1 != 0
        LOAD  R2, arr(R0)     ; первое слово массива
        HALT
```

## Псевдокоманды

Ассемблер заменяет их обычными командами. Каждая занимает одно слово.

| Псевдокоманда | Раскрывается в | Действие |
| --- | --- | --- |
| `NOP` | `ADD R0, R0, R0` | ничего не делает (флаги меняются) |
| `MOV rd, rs` | `ADD rd, rs, R0` | копирует регистр |
| `LI rd, imm` | `ADDI rd, R0, imm` | загружает число |

`LI` принимает число в пределах `imm` (18 бит со знаком). Как и `ADDI`, обе команды `ADD` меняют флаги.

## Регистр букв

Не важен везде: мнемоники, регистры, директивы, метки и имена `.equ`. `ADD`, `add` и `Add` — одно и то же, `loop:` и `LOOP` — одна метка.
