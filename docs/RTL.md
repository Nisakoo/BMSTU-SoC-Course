| Провод | Откуда | Куда | За что отвечает |
| --- | --- | --- | --- |
| `next` (`10`) | Логика PC | PC | следующий адрес команды |
| `PC` (`10/PC`) | PC | ROM инструкций (`addr`) | адрес читаемой команды |
| `PC` (обратная связь) | PC | Логика PC | текущий адрес для вычисления следующего |
| `I` (`32/I`) | ROM инструкций | IR | слово команды |
| `[31:26]` | IR | MUX перед ROM микрокоманд (`IR`) | opcode текущей команды |
| `[21:18]` | IR | `ra1` регистрового файла | номер регистра `rs1` |
| `[17:14]` | IR | MUX перед `ra2` (вход `0`) | номер регистра `rs2` |
| `[25:22]` | IR | MUX перед `ra2` (вход `1`) и `wa` регистрового файла | номер регистра `rd` |
| `[17:0]` | IR | Знаковое расширение | константа `imm`, 18 бит |
| `imm` (`32/imm`) | Знаковое расширение | MUX B (вход `1`), Логика PC | константа, расширенная до 32 бит |
| `FETCH` | константа | MUX перед ROM микрокоманд | opcode микропрограммы выборки |
| `ph` | Фаза | MUX перед ROM микрокоманд | выбор: `FETCH` (выборка) или `IR` (выполнение) |
| `op` (`6`) | MUX | ROM микрокоманд | старшие 6 бит адреса микрокоманды |
| `mPC` (`4/mPC`) | mPC | ROM микрокоманд | номер шага, младшие 4 бита адреса микрокоманды |
| `last` | ROM микрокоманд | mPC | сбросить счётчик шагов |
| `last` | ROM микрокоманд | Фаза | сменить фазу |
| `CTRL` | ROM микрокоманд | управляющие входы блоков | слово микрокоманды, из него берутся сигналы ниже |
| `ra2` | MUX перед `ra2` | регистровый файл | номер регистра для второго чтения |
| `rd1` | регистровый файл | АЛУ (`A`) | первый операнд |
| `rs1` | `rd1` регистрового файла | Логика PC | адрес перехода по регистру |
| `rd2` | регистровый файл | MUX B (вход `0`) | второй операнд |
| `rdata2` | `rd2` регистрового файла | Декодер адреса (`wd`) | данные для записи в память |
| `B` | MUX B | АЛУ | второй операнд АЛУ |
| `R` (`32/R`) | АЛУ | MUX WB (вход `3`), Регистр адреса | результат АЛУ; адрес обращения к данным |
| `NZCV` (`4`) | АЛУ | Флаги | флаги результата |
| `Z` | Флаги | Логика PC | условие перехода |
| `PC+1` | Логика PC | MUX WB (вход `1`) | адрес возврата для `JAL` |
| `wd` (`32/wd`) | MUX WB | регистровый файл | данные для записи в регистр |
| `addr` (`32`) | Регистр адреса | Декодер адреса | адрес данных |
| `ram`, `bus` | Декодер адреса | RAM (в обе стороны) | адрес, запись и чтение RAM |
| `mmio`, `bus` | Декодер адреса | MMIO (в обе стороны) | адрес, запись и чтение регистров MMIO |
| `MEM_RD` | Декодер адреса (`rd`) | MUX WB (вход `2`) | данные, прочитанные из RAM или MMIO |
| `t` | Таймер | MMIO | значение таймера для чтения программой |
| `t` (`32/t`) | Таймер | Захват | значение, которое фиксируется по фронту кнопки |
| `arm` | MMIO | Захват | взвод захвата |
| `кнопка` (`btn`) | внешний вывод | Захват | кнопка реакции |
| `CAPT` | Захват | MUX WB (вход `0`) | захваченное значение таймера (`HIGH_RES_TICK`) |
| `NOCAP` | Захват | Флаги | «захвата не было», попадает в Z |
| `кнопки, концевые, ИК` | внешние выводы | MMIO | кнопки пульта, концевые выключатели, ИК-датчик |
| `LED, 7-сегм., ворота` | MMIO | внешние выводы | светодиод, 7-сегментный дисплей, привод ворот |
| `CLK` | — | PC, IR, mPC, Фаза, регистровый файл, Флаги, Регистр адреса, Таймер, Захват | тактовый сигнал (общий провод на схеме не нарисован) |
| `pc_we` | CTRL | PC | записать новое значение |
| `pc_src`, `pc_cond` | CTRL | Логика PC | источник нового PC; условие по Z |
| `ir_we` | CTRL | IR | записать команду из ROM |
| `rs2_sel` | CTRL | MUX перед `ra2` | `rs2` или `rd` |
| `reg_we` | CTRL | регистровый файл | записать `wd` в регистр `wa` |
| `alu_b_sel` | CTRL | MUX B | `rd2` или `imm` |
| `alu_op` | CTRL | АЛУ | операция |
| `flags_we` | CTRL | Флаги | обновить флаги |
| `wb_sel` | CTRL | MUX WB | источник записи в регистр |
| `mem_re`, `mem_we` | CTRL | Декодер адреса | чтение и запись данных |
