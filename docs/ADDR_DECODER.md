# Декодер адреса

Выбирает, к какой области памяти данных относится обращение (RAM, видеопамять или MMIO), передаёт запись только ей и возвращает прочитанное слово. Комбинационный блок. Код: `rtl/addr_decoder.v`.

## Карта адресов

Адреса в словах, подробнее в [ISA.md](ISA.md).

| Область | Адреса | Размер | Условие выбора |
| --- | --- | --- | --- |
| RAM | `0x00000000`–`0x000003FF` | 1024 слова | `addr[31:10] = 0` |
| Видеопамять | `0x00001000`–`0x00001FFF` | 4096 слов | `addr[31:12] = 1` |
| MMIO | `0xFFFFFC00`–`0xFFFFFFFF` | 1024 адреса | `addr[31:10]` — все единицы |

Адреса вне этих областей пусты.

## Порты

| Порт | Ширина | Направление | Откуда / куда |
| --- | --- | --- | --- |
| `addr` | 32 | вход | регистр адреса |
| `we` | 1 | вход | `mem_we` из микрокоманды |
| `ram_rd` | 32 | вход | чтение из RAM |
| `vram_rd` | 32 | вход | чтение из видеопамяти |
| `mmio_rd` | 32 | вход | чтение из MMIO |
| `ram_addr` | 10 | выход | адрес в RAM |
| `ram_we` | 1 | выход | запись в RAM |
| `vram_addr` | 12 | выход | адрес в видеопамяти |
| `vram_we` | 1 | выход | запись в видеопамять |
| `mmio_addr` | 10 | выход | адрес в MMIO |
| `mmio_we` | 1 | выход | запись в MMIO |
| `rd` | 32 | выход | прочитанное слово, в MUX WB (`MEM_RD`) |

Данные для записи (`rdata2`) в декодер не заходят: они идут на RAM, видеопамять и MMIO напрямую.

## Работа

- **Адрес внутри области** — младшие биты `addr`: 10 бит для RAM и MMIO, 12 бит для видеопамяти.
- **Запись.** Из трёх выходов `*_we` равен 1 только у выбранной области и только если `we = 1`. Остальные равны 0.
- **Чтение.** `rd` равен слову от выбранной области. Шины чтения невыбранных областей на `rd` не влияют.
- **Пустые адреса.** Чтение даёт 0, запись игнорируется: все `*_we` равны 0.

## MMIO через `R0`

Адреса MMIO достаются командами `LOAD` и `STORE` вида `imm(R0)` с отрицательным смещением. `imm` от −1024 до −1 после знакового расширения даёт адреса `0xFFFFFC00`–`0xFFFFFFFF`, то есть `mmio_addr = imm + 1024`.

## Проверка

Тесты находятся в `tests/addr_decoder_test.rs`, 9 проверок:
- границы областей (первый, последний и соседние адреса);
- все адреса каждой области: выбор, `*_we`, чтение;
- адрес внутри области равен смещению для всех адресов;
- все 4 194 304 значения старших 22 бит адреса;
- адреса с одним установленным и с одним сброшенным битом;
- пустые адреса: чтение 0, запись игнорируется;
- отсутствие `*_we` при `we = 0`;
- чтение только от выбранной области;
- доступ к MMIO через отрицательное смещение от `R0`.
