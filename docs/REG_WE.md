# Регистр с разрешением записи

Универсальный регистр: синхронный сброс, запись по сигналу `we`. Один модуль с параметром ширины заменяет отдельные регистры схемы. Код: `rtl/reg_we.v`.

## Параметр

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `WIDTH` | 32 | ширина регистра в битах |

## Порты

| Порт | Ширина | Направление | Назначение |
| --- | --- | --- | --- |
| `clk` | 1 | вход | тактовый сигнал, всё происходит по фронту 0 → 1 |
| `reset` | 1 | вход | синхронный сброс в 0 |
| `we` | 1 | вход | разрешение записи |
| `d` | `WIDTH` | вход | данные для записи |
| `q` | `WIDTH` | выход | хранимое значение |

## Работа

На каждом фронте `clk` выполняется одно действие, по приоритету:

| Приоритет | Условие | Новое значение `q` |
| --- | --- | --- |
| 1 | `reset = 1` | 0 |
| 2 | `we = 1` | `d` |
| 3 | иначе | без изменений |

- Сброс синхронный: пока нет фронта `clk`, изменение `reset` на `q` не влияет.
- Если `reset` и `we` равны 1 одновременно, выполняется сброс.
- Запись происходит только по фронту `clk` 0 → 1. Спад `clk` и изменение `d` между фронтами значение не меняют.
- До первого сброса значение `q` не определено.

## Где используется

Один и тот же модуль служит нескольким регистрам схемы:

| Регистр | `WIDTH` | `we` | `d` | `q` |
| --- | --- | --- | --- | --- |
| IR | 32 | `ir_we` | слово из ROM инструкций | текущая команда |
| Регистр флагов | 4 | `flags_we` | `nzcv` из АЛУ | флаги N, Z, C, V |
| Регистр адреса | 10 | `addr_we` (в `RTL.drawio` пока не нарисован) | младшие биты результата АЛУ | адрес данных |
| PC | 10 | `pc_we` | следующий адрес из «Логики PC» | адрес текущей команды |

Пример создания внутри другого модуля:

```verilog
reg_we #(.WIDTH(4)) u_flags (
    .clk  (clk),
    .reset(reset),
    .we   (flags_we),
    .d    (nzcv),
    .q    (flags)
);
```

## Проверка

Макрос `#[verilog]` в Rust не принимает выражения в ширине портов (`[WIDTH-1:0]`), поэтому тесты подключают регистр через обёртку с фиксированной шириной:

| Файл | Модуль | Ширина |
| --- | --- | --- |
| `tests/rtl/reg_we32.v` | `reg_we32` | 32 |

Тесты находятся в `tests/reg_we_test.rs`, 13 проверок для ширины 32: значение после сброса, запись, все 32 бита и каждый бит отдельно, перезапись, `we = 0`, удержание значения на многих тактах, запись после простоя, запись только по фронту `clk`, сброс, синхронность сброса, приоритет сброса над записью, запись после сброса.
