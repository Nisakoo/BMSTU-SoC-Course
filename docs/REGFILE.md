# Регистровый файл

16 регистров по 32 бита с двумя портами чтения и одним портом записи. Код: `rtl/regfile.v`.

## Порты

| Порт | Ширина | Направление | Откуда / куда |
| --- | --- | --- | --- |
| `clk` | 1 | вход | тактовый сигнал |
| `reset` | 1 | вход | синхронный сброс |
| `ra1` | 4 | вход | номер регистра для порта чтения 1: поле `rs1` команды, `IR[21:18]` |
| `ra2` | 4 | вход | номер регистра для порта чтения 2: выход MUX, `rs2` (`IR[17:14]`) или `rd` (`IR[25:22]`) |
| `wa` | 4 | вход | номер регистра для записи: поле `rd` команды, `IR[25:22]` |
| `wd` | 32 | вход | данные для записи из MUX WB |
| `we` | 1 | вход | разрешение записи, сигнал `reg_we` из микрокоманды |
| `rd1` | 32 | выход | первый операнд АЛУ (`a`) и `rs1` в «Логику PC» |
| `rd2` | 32 | выход | MUX B и данные для записи в память (`rdata2`) |

## Работа

**R0.** Регистр R0 всегда равен 0. Чтение R0 возвращает 0, запись в R0 игнорируется (`wa = 0` ничего не меняет).

**Чтение.** Комбинационное: `rd1` и `rd2` показывают значения регистров `ra1` и `ra2` сразу, без такта, и меняются вслед за адресом. Порты независимы: на них можно читать разные регистры и один и тот же.

**Запись.** По фронту `clk` в регистр `wa` записывается `wd`, если `we = 1` и `wa` не равен 0. За один такт записывается не больше одного регистра. Если `we = 0`, регистры не меняются.

**Сброс.** Синхронный: по фронту `clk` при `reset = 1` все 16 регистров становятся 0. Сброс приоритетнее записи, при `reset = 1` и `we = 1` одновременно запись не выполняется. Без фронта `clk` изменение `reset` на регистры не влияет.

**Чтение и запись в одном такте.** Пока фронта `clk` не было, чтение регистра, в который идёт запись, возвращает старое значение. После фронта `clk` оно возвращает новое.

## Приоритеты на фронте clk

| Приоритет | Условие | Действие |
| --- | --- | --- |
| 1 | `reset = 1` | все регистры = 0 |
| 2 | `we = 1` и `wa != 0` | `регистр[wa] = wd` |
| 3 | иначе | регистры не меняются |

## Проверка

Тесты находятся в `tests/regfile_test.rs`, 13 проверок: сброс, запись и чтение каждого регистра, R0, `we`, независимость портов, комбинационное чтение, запись только по фронту, синхронность сброса, приоритет сброса над записью.
